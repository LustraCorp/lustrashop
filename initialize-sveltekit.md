# Initialize a SvelteKit Project

Follow these steps to create a new SvelteKit project:

1. **Install Node.js**: Ensure you have Node.js installed on your machine. You can download it from [nodejs.org](https://nodejs.org/).

2. **Create a new SvelteKit project**:
   - Open your terminal.
   - Navigate to the directory where you want to create your project.
   - Run the following command to create a new SvelteKit project:
     ```bash
     npm create svelte@latest lustrashop-svelte
     ```
   - Replace `my-sveltekit-app` with your desired project name.

3. **Navigate to the project directory**:
   ```bash
   cd lustrashop-svelte
   ```

4. **Install dependencies**:
   ```bash
   npm install
   ```

5. **Start the development server**:
   ```bash
   npm run dev -- --open
   ```
   This will start the development server and open your new SvelteKit app in your default web browser.
